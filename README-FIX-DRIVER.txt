رفع گام ۳ — راننده گاهی انتخاب می‌شد، گاهی نه
════════════════════════════════════════════════════

نشانه‌ای که گزارش کردی
  «پلاک را وارد می‌کند ولی اسم راننده را تشخیص نمی‌دهد.
   دو بار تست کردم، یک بار درست رفت مرحله بعد، بار بعدی نتوانست.»

این «گاهی می‌شود گاهی نه» کلید تشخیص بود: نشانه‌ی مسابقه‌ی
زمانی (race condition)، نه غلط بودن داده.

سه باگ پیدا شد
─────────────────────────────────────────────────────
۱) حلقه‌ی انتظار غلط  ← علت اصلی نوسان
     if (n > 1) break
   کل option ها شمرده می‌شد، و گزینه‌ی «انتخاب کنید» همیشه هست.
   بدتر از آن: اگر AJAX تا پایان حلقه نمی‌آمد، کد بدون هیچ خطایی
   جلو می‌رفت و فهرست خالی را می‌خواند.
   سرعت پاسخ سایت هر بار فرق می‌کند ⇒ یک بار موفق، بار بعد نه.

   حالا: فقط گزینه‌های واقعی شمرده می‌شوند، انتظار فعال تا ۲۰ ثانیه،
   و اگر نیامد صریحا خطا می‌دهد به‌جای رد شدن بی‌صدا.

۲) «ی» عربی در برابر فارسی  ← علت پیدا نشدن نام
   سایت می‌نویسد  علي  با ي عربی   (U+064A)
   تو می‌نویسی    علی  با ی فارسی  (U+06CC)
   برای چشم یکسان، برای کد کاملا متفاوت. همین برای ک/ك هم هست.

   حالا حروف یکسان‌سازی می‌شوند:
        ي ى → ی        ك → ک        آ أ إ → ا       ة → ه
        اعراب و کشیده و نیم‌فاصله حذف

۳) کد ملی عملا بررسی نمی‌شد
   شرط داخل حلقه بود و چون تطبیق نام اول می‌آمد، هرگز به کد ملی
   به‌عنوان راه دوم نمی‌رسید.

روش تطبیق جدید — پنج مرحله، به ترتیب اطمینان
─────────────────────────────────────────────────────
  ۱. کد ملی  (مطمئن‌ترین — از JSON مقدار و از متن، با ارقام فارسی)
  ۲. نام کامل
  ۳. اجزای نام  (ترتیب نام/فامیل مهم نیست: «پرون علی» هم پیدا می‌شود)
  ۴. نام داخل JSON مقدار
  ۵. اگر فقط یک راننده در فهرست باشد، همان

نتیجه‌ی تست روی داده‌ی واقعی سایت
     نام="علی پرون"  کدملی=""            → پیدا شد [نام کامل]
     نام="علي پرون"  کدملی=""            → پیدا شد [نام کامل]
     نام="پرون علی"  کدملی=""            → پیدا شد [اجزای نام]
     نام=""          کدملی="3070427898"  → پیدا شد [کد ملی]
     نام="علی پرون"  کدملی="۳۰۷۰۴۲۷۸۹۸"  → پیدا شد [کد ملی]
     نام="حسن نادری" کدملی=""            → پیدا نشد ✔ (درست رد شد)

همین اصلاح انتظار روی فهرست پلاک هم اعمال شد، چون دقیقا همان
ضعف را داشت و دیر یا زود همان مشکل را می‌ساخت.

اگر باز هم پیدا نشد
  حالا لاگ، فهرست کامل راننده‌های موجود در سایت را چاپ می‌کند:
       ✖ راننده «...» در فهرست پیدا نشد
          فهرست موجود در سایت:
             • علي پرون (3070427898)
  آن فهرست را برایم بفرست.

توصیه: در پروفایل حتما «کد ملی راننده» را پر کن — مطمئن‌ترین راه
تطبیق است و به املای نام حساس نیست.

نصب
  ۱) روی ریشه‌ی پروژه اکسترکت کن (Replace)
  ۲) پنجره‌ی Worker را ببند و باز کن
  ۳) مرکز کنترل → تعداد ۲ یا ۳ (تا نوسان را ببینی)
