# قابلیت فوروارد پیامک — راهنمای نصب

این پچ یک قابلیت کامل جدید اضافه می‌کند: دریافت پیامک فوروارد شده از گوشی (حاوی لینک)، ذخیره‌اش، و باز کردن آن لینک داخل همان نشست مرورگر مربوط به حساب باربرگ.

## فایل‌های جدید/تغییر یافته
- `prisma/schema.prisma` — دو فیلد جدید روی `BarBargAccount` (`phone`, `smsWebhookToken`) + مدل جدید `SmsMessage`
- `prisma/migrations/20260714120000_add_sms_forwarding/` — مایگریشن SQL متناظر
- `src/app/api/sms/webhook/[token]/route.ts` — **وبهوک عمومی** که اپ فورواردر پیامک روی گوشی به آن POST می‌زند
- `src/app/api/sms/messages/*` — روت‌های لیست/حذف/استفاده از پیامک‌های دریافتی
- `src/app/api/barbarg-accounts/[id]/sms-token/route.ts` — ساخت/تعویض توکن وبهوک هر حساب
- `src/app/api/barbarg-accounts/[id]/route.ts` — بروزرسانی برای پشتیبانی از فیلد `phone`
- `src/automation/auth/SmsLinkFlow.ts` — باز کردن لینک با Playwright داخل نشست حساب (فقط دامنه `barname.utcms.ir` مجاز است)
- `src/components/sms/SmsForwardCenter.tsx` + `src/app/(panel)/panel/sms/page.tsx` — صفحه پنل
- `src/components/layout/Sidebar.tsx` — لینک منو به صفحه جدید (زیر بخش «اتوماسیون»)

## نصب
1. این فایل‌ها را روی همون مسیر در پروژه اصلی کپی/بازنویسی کن (مسیرها دقیقاً حفظ شده).
2. اجرا کن:
   ```
   npx prisma migrate deploy
   npx prisma generate
   ```
3. سرور رو دوباره بالا بیار.

## استفاده
1. برو به منوی «اتوماسیون → فوروارد پیامک» → تب «آدرس وبهوک حساب‌ها».
2. برای حساب مورد نظر، شماره تلفنی که پیامک‌هاش باید فوروارد بشه رو ثبت کن (فقط جنبه‌ی اطلاعاتی داره).
3. دکمه «ساخت آدرس وبهوک» رو بزن؛ یک URL مثل زیر ساخته می‌شه:
   ```
   https://YOUR-DOMAIN/api/sms/webhook/<token طولانی و تصادفی>
   ```
4. روی گوشی که پیامک‌های اون حساب رو می‌گیره، یه اپ SMS Forwarder (مثل «SMS Forwarder» یا Macrodroid/Tasker) نصب کن و تنظیمش کن که پیامک‌های دریافتی رو با POST (یا GET) به همین آدرس بفرسته. اکثر این اپ‌ها فیلد بدنه رو با اسم `message` یا `text` یا `body` می‌فرستن که این وبهوک هر سه رو پشتیبانی می‌کنه.
5. وقتی پیامکی برسه، توی تب «پیامک‌های دریافتی» نشون داده می‌شه. اگه پیامک حاوی لینک باشه، یک دکمه‌ی «استفاده از لینک» ظاهر می‌شه که با کلیک روش، همون لینک رو داخل نشست مرورگر (Playwright) همون حساب باز می‌کنه و نشست رو دوباره ذخیره می‌کنه.

## نکات مهم / محدودیت‌هایی که باید بدونی
- **این وبهوک، عمومی و بدون احراز هویت کوکی‌ای هست** (چون از گوشی میاد نه از پنل) — امنیتش فقط روی توکن تصادفی ۴۸ کاراکتری تکیه داره. توکن رو جایی به اشتراک نذار و اگه لو رفت، از دکمه‌ی 🔄 برای ساخت توکن جدید استفاده کن.
- من مطمئن نیستم دقیقاً barname.utcms.ir چه نوع لینکی توی پیامک می‌فرسته (لینک تایید OTP؟ لینک ورود یک‌بار‌مصرف؟) — چون تو کد پروژه هیچ نمونه‌ای از این پیامک یا مستنداتی از فلوی دقیق‌ش پیدا نکردم. به همین خاطر `SmsLinkFlow` فقط لینک رو باز می‌کنه و نتیجه (URL نهایی بعد از باز شدن + اسکرین‌شات) رو ذخیره می‌کنه؛ اگه لینک نیاز به مرحله‌ی اضافه‌ای داشته باشه (مثلاً کلیک روی یه دکمه‌ی تایید بعد از باز شدن لینک)، باید بعد از تست با یه پیامک واقعی، این فایل رو تکمیل کنم.
- اگه حساب هنوز هیچ نشست/سشن ذخیره‌شده‌ای نداشته باشه (یعنی هیچ‌وقت لاگین نشده)، دکمه‌ی «استفاده از لینک» با خطای «نشست فعالی یافت نشد» مواجه می‌شه — باید حداقل یک بار لاگین دستی/خودکار انجام بشه تا سشن ساخته بشه.
