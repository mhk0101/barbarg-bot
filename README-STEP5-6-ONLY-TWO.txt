گام ۵ و ۶ — فقط دو ورودی، جای دیگر دست نمی‌خورد
════════════════════════════════════════════════════════

چیزی که گفتی
────────────────────────────────────────────────────────
«فقط باید در اون دوتا ورودی وارد شود، جای دیگه چیزی وارد نشه»

و placeholderها را فرستادی:
   MapCity        → «شهرستان مورد نظر را انتخاب نمایید»
   AddressSearch  → «شهر/روستا/محله مورد نظر...»

پس AddressSearch آدرس نمی‌خواهد — شهر/روستا/محله می‌خواهد.
نسخه‌ی قبلی که فرستادم آدرس در آن تایپ می‌کرد. اشتباه بود، درست شد.


حالا دقیقا چه اتفاقی می‌افتد
────────────────────────────────────────────────────────
گام ۵ (مبدا):
   ورودی ۱/۲ →  MapCity        ← نام شهرستان
   ورودی ۲/۲ →  AddressSearch  ← نام شهر/روستا/محله

گام ۶ (مقصد):
   ورودی ۱/۲ →  MapCity2       ← نام شهرستان
   ورودی ۲/۲ →  AddressSearch2 ← نام شهر/روستا/محله

و بس. هیچ چیز دیگری لمس نمی‌شود:
   ✗ #ddStateSource / #ddStateDest   (استان)      — دست نمی‌خورد
   ✗ #ddCitySource  / #ddCityDest    (شهر قدیمی)  — دست نمی‌خورد
   ✗ #sourcePostalCode / #destPostalCode (کدپستی) — دست نمی‌خورد
   ✗ #txtAddressSource / #txtAddressDest (آدرس)   — دست نمی‌خورد


چطور مطمئن شدم اشتباهی جای دیگر ننویسد
────────────────────────────────────────────────────────
۱) کدِ پر کردنِ آن چهار فیلد حذف نشده، ولی پشت یک کلید خاموش
   رفته است:

       const FILL_ONLY_TWO = true
       ...
       if (!FILL_ONLY_TWO) { ... }

   تا وقتی true است، اجرا نمی‌شود. اگر روزی لازم شد، فقط همان
   یک خط را false کن. (حذفش نکردم چون گفتی بدون اجازه دست نزنم.)

۲) پیش از تایپ، placeholder همان فیلد خوانده و بررسی می‌شود:
       MapCity        باید شامل «شهرستان» باشد
       AddressSearch  باید شامل «شهر» یا «روستا» یا «محله» باشد
   اگر نبود، اصلا تایپ نمی‌کند، عکس wrongfield.png می‌گیرد و
   با پیام خطا برمی‌گردد. یعنی اگر سایت شناسه‌ها را جابه‌جا کند،
   ربات بی‌سروصدا در فیلد اشتباه نمی‌نویسد.

۳) قفل aria-controls که نسخه‌ی قبل اضافه شد سر جایش است:
       input.select2-search__field[aria-controls="select2-MapCity-results"]
   و درست پیش از تایپ، document.activeElement بررسی می‌شود.


داده از کجا می‌آید
────────────────────────────────────────────────────────
   شهرستان        ←  originCounty  یا اگر نبود  originCity
   شهر/روستا/محله ←  originLocality یا اگر نبود  originCity
   (و همین‌طور dest برای گام ۶)

⚠ صادقانه: ستون‌های originCounty و originLocality در
   prisma/schema.prisma وجود ندارند (چک کردم). پس عملا هر دو
   ورودی همان originCity را می‌گیرند — یعنی هر دو «سیرجان».
   اگر سایت برای این دو چیز متفاوتی می‌خواهد، باید دو فیلد
   جدید در فرم پروفایل اضافه کنم. بگو تا انجام دهم.
