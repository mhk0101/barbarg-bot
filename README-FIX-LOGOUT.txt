رفع دکمه‌ی «خروج» در منوی کاربر
════════════════════════════════════════════════════

فایل: src/components/layout/Header.tsx

علت
─────────────────────────────────────────────────────
پروژه از کتابخانه‌ی Base UI استفاده می‌کند
(@base-ui/react/menu) ولی کد با سبک Radix نوشته شده بود:

    <DropdownMenuItem onSelect={() => signOut(...)}>

در Base UI اصلا prop به اسم onSelect وجود ندارد.
رویداد درستش onClick است.

چون onSelect برای Base UI ناشناخته است، صرفا به‌عنوان یک
ویژگی اضافی روی عنصر DOM پاس می‌شود و هیچ‌وقت صدا زده
نمی‌شود. نه خطا می‌دهد، نه کار می‌کند — فقط سکوت.

تایید از مستندات رسمی Base UI:
    «control the dialog state and open it imperatively
     using the onClick handler on the menu item»
    <Menu.Item onClick={() => setDialogOpen(true)}>


نکته: «تنظیمات» هم خراب بود
─────────────────────────────────────────────────────
همان اشکال را داشت، فقط هنوز امتحانش نکرده بودی.
هر دو با هم رفع شدند. در کل پروژه فقط همین دو مورد
onSelect داشتند.


چه چیزی تغییر کرد
─────────────────────────────────────────────────────
۱) onSelect  →  onClick   (هر دو آیتم)

۲) تابع handleSignOut اضافه شد با محافظ:
   اگر signOut به‌خاطر خطای شبکه یا CSRF پرت شود،
   کاربر در پنل گیر نمی‌کند و دستی به /login هدایت می‌شود.

۳) محافظ کلیک تکراری: در حین خروج، دکمه غیرفعال می‌شود
   و متنش به «در حال خروج…» تغییر می‌کند.
