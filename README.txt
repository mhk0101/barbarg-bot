رفع دکمه‌ی زنگوله (اعلان‌ها)
══════════════════════════════════════════════════════

مشکل
──────────────────────────────────────────────────────
دکمه‌ی زنگوله در نوار بالا:

   <Button variant="ghost" size="icon" className="relative rounded-xl">
     <Bell />
     <Badge>۳</Badge>
   </Button>

  • هیچ onClick نداشت  →  کلیک هیچ کاری نمی‌کرد
  • عدد «۳» هاردکد بود  →  همیشه ۳، حتی اگر هیچ اعلانی نبود

یک نگهدارنده‌ی جا بود که هیچ‌وقت تکمیل نشده بود.


نکته‌ی جالب
──────────────────────────────────────────────────────
همه‌ی زیرساختش از قبل آماده بود:
   • مدل Notification در دیتابیس  ✔
   • API کامل /api/notifications (GET/POST/PUT/DELETE)  ✔
   • صفحه‌ی /panel/notifications با علامت‌گذاری خوانده‌شده  ✔
   • لینکش در سایدبار زیر «اعلان‌ها»  ✔

فقط زنگوله به هیچ‌کدام وصل نبود.


چه چیزی تغییر کرد
──────────────────────────────────────────────────────
۱) src/components/layout/Header.tsx

   • کلیک روی زنگوله  →  /panel/notifications
   • عدد واقعی از /api/notifications?unread=true خوانده می‌شود
   • هر ۳۰ ثانیه تازه می‌شود، و با هر جابه‌جایی بین صفحات
   • وقتی تب مخفی است درخواست نمی‌زند (صرفه‌جویی)
   • اگر صفر باشد، نشان قرمز اصلا نمایش داده نمی‌شود
   • بیشتر از ۹۹ → «۹۹+»
   • ارقام فارسی: ۱، ۳، ۱۲، ۹۹+
   • tooltip: «۵ اعلان خوانده‌نشده»

۲) worker/processor.ts

   مشکل بعدی: هیچ‌کس اعلان نمی‌ساخت، پس زنگوله همیشه
   خالی می‌ماند. حالا ورکر برای سه رویداد مهم اعلان می‌سازد:

      ✅ بارنامه ثبت شد     → «کد رهگیری ۱۳۰۶۲۶۲۵۶۸»   (سبز)
      🛑 خطای دائمی        → «نیاز به بررسی»           (قرمز)
      🚫 بلاک IP / WAF     → «بعد از ۲۰ تلاش متوقف شد»  (قرمز)

   عمدا برای هر خطای کوچکی اعلان نمی‌سازد — وگرنه زنگوله
   پر از نویز می‌شود و بی‌ارزش.


نصب
  ۱) روی ریشه‌ی پروژه اکسترکت کن (Replace)
  ۲) پنجره‌ی Worker را ببند و باز کن
  ۳) Ctrl+F5

بعد از نصب، احتمالا نشان قرمز ناپدید می‌شود (چون واقعا
اعلانی وجود ندارد). این درست است — عدد ۳ قبلی دروغ بود.

بعد از اولین ثبت موفق یا اولین خطای دائمی، نشان ظاهر
می‌شود و با کلیک روی زنگوله جزئیاتش را می‌بینی.
