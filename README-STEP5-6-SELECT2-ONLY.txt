گام ۵ و ۶ — فقط دو ورودی (استان از پنل + محله) — نسخه ۲
════════════════════════════════════════════════════════

این پچ دقیقا همان چیزی است که خواستی:

  ۱) برنامه «استان» را از پنل ربات می‌گیرد:
       • اگر تیک «تشخیص خودکار استان از روی پلاک» روشن باشد (پیش‌فرض)،
         استان از کد ایران پلاک تشخیص داده می‌شود
         (مثلا «ایران ۷۵» → بوشهر) و هنگام ذخیره‌ی پروفایل خودکار
         در پروفایل نوشته می‌شود
       • اگر تیک خاموش باشد، همان استانی که خودت انتخاب کرده‌ای
  ۲) استان در ورودی «شهرستان مورد نظر را انتخاب نمایید» (MapCity/MapCity2)
     تایپ می‌شود → صبر تا لیست بالا بیاید → انتخاب
  ۳) مقدار «شهر مبدا/مقصد» پنل (جایی که محله/روستا را می‌گذاری، مثل
     «شهید نظام احسایی، خیابان میرزا رضا») در ورودی
     «شهر/روستا/محله مورد نظر...» (AddressSearch/AddressSearch2)
     تایپ می‌شود → صبر تا لیست بالا بیاید → انتخاب
  ۴) «آدرس مبدا/مقصد» پنل دیگر اجباری نیست (اختیاری شد) — چون
     نقشه‌ی خود سایت بعد از انتخاب شهرستان و محله، آدرس متنی را پر می‌کند
  ۵) هیچ فیلد دیگری در گام ۵/۶ دست نمی‌خورد

───────────────────────────────────────────────────────────────────────
فایل‌های تغییر یافته (این نسخه)
───────────────────────────────────────────────────────────────────────
  ۱) src/automation/engine/step1-engine.js
       • زنجیره‌ی تایپ MapCity: اول «استان» (از پنل/پلاک)، بعد شهرستان
         (فقط اگر شبیه آدرس نباشد — «خیابان...» در کادر شهرستان تایپ نمی‌شود)
       • زنجیره‌ی تایپ AddressSearch: اول «شهر مبدا/مقصد» پنل (محله)،
         بعد محله‌ی جدا، بعد بخش اول آدرس (بدون رقم هم امتحان می‌شود:
         «سرتل ۳۹» → «سرتل ۳۹» → «سرتل»)
       • «آدرس» از فیلدهای اجباری validateData حذف شد
       • «موردی یافت نشد.» موقتی دیگر گام را نمی‌خواباند (تا ۴ بار دوباره‌چک)
       • بعد از هر تایپ: ۲ ثانیه صبر ثابت + پایش تا ۳۰ ثانیه برای بالا آمدن لیست

  ۲) src/app/(panel)/panel/profiles/page.tsx
       • «آدرس مبدا/مقصد» اختیاری شد (لیبل بدون ستاره + حذف از قوانین
         اجباریِ فرم و حذف از لیست الزامی هنگام ذخیره)
       • در حالت «تشخیص خودکار»، استانِ تشخیص‌داده‌شده از پلاک هنگام
         ذخیره‌ی پروفایل خودکار داخل پروفایل نوشته می‌شود
         (تا API رد نکند و موتور از پنل بردارد)
       • placeholder شهر مبدا/مقصد: «شهر، محله یا روستا — مثلا سیرجان، ریشهر»

  ۳) README-STEP5-6-SELECT2-ONLY.txt (همین فایل)

  ═══ گام ۵: مبدا بارگیری ═══
  ⓘ استان از پلاک «75 ع 923 ایران 17» تشخیص داده شد: کرمان
  → MapCity (شهرستان): تایپ «کرمان» — صبر تا لیست...
  ⌨ در «MapCity» تایپ شد: «کرمان» — صبر تا لیست بالا بیاید...
  ⓘ 2 نتیجه: کرمان | شهرستان کرمان
  ✔ MapCity (شهرستان) = «کرمان»
  → AddressSearch (شهر/روستا/محله): تایپ «شهید نظام احسایی، خیابان میرزا رضا» — صبر تا لیست...
  ✔ AddressSearch (شهر/روستا/محله) = «شهید نظام احسایی، خیابان میرزا رضا»

نصب
───────────────────────────────────────────────────────────────────────
  ۱) هر دو فایل را در همان مسیرها جایگزین کن (مسیرها حفظ شده)
  ۲) Worker را ری‌استارت کن:  npm run worker
  ۳) پنل → پروفایل‌ها → یک پروفایل را باز کن:
       - پلاک را کامل وارد کن (برای تشخیص استان)
       - در «شهر مبدا/مقصد» نام محله یا روستا را بنویس (مثلا «ریشهر»
         یا «شهید نظام احسایی، خیابان میرزا رضا»)
       - «آدرس» را می‌توانی خالی بگذاری
       - ذخیره کن و از «مرکز کنترل اتوماسیون» به صف اضافه کن
  ۴) یک جاب تست بزن

نکته
────
  اگر پروفایل قدیمی‌ای داری که در حالت خودکار ذخیره شده و استانش
  خالی است، یک بار همان پروفایل را باز کن و دوباره «ذخیره» بزن تا
  استانِ تشخیص‌داده‌شده داخلش نوشته شود.
